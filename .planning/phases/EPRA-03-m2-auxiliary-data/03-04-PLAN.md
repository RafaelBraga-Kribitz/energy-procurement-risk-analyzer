| dataset name → _io.raw_month_path | dataset identifier reaches filesystem path construction |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-05 | Denial of Service | parse_geojson / _fetch_geosphere | medium | mitigate | Validate top-level GeoJSON shape before deep-indexing; `requests.get(..., timeout=...)`; raise on malformed/oversized response rather than crash or silently empty (Pitfall 5) |
| T-03-06 | Tampering | dataset → raw_month_path | high | mitigate | Persist only via `_io.write_month("geosphere_graz_daily", ...)` — the `_DATASET_NAME_RE` allowlist guards path traversal; no hand-built path in geosphere.py |
| T-03-11 | Tampering | ING-094 threshold integrity | medium | mitigate | Plausibility bands are fixed constants; a failing gate raises (EN-061) and is never widened without an ADR (A-2) |
| T-03-SC | Tampering | pip installs | low | accept | No new packages — reuses `requests`/`pandas`/`pyarrow` pinned/vetted in M1 (RESEARCH §Package Legitimacy Audit) |
</threat_model>
